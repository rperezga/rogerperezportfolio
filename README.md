# rperezga.github.io/rogerperezportfolio

My personal portfolio — https://rperezga.github.io/rogerperezportfolio/

Rebuilt 2026: plain HTML/CSS/JS, zero dependencies, no build step. Bilingual EN/ES
(English in the markup for SEO; Spanish overrides in `app.js`), automatic light/dark
theme via `prefers-color-scheme`, and a cleanup routine that unregisters the 2020
service worker so returning visitors stop seeing the cached old site.
